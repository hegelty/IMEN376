## 2. Layer A — 전체 알코올 맥주 국내 출고량 (정확도 백본)

### 수집 목표
KOSIS 광업·제조업동향조사(`DT_1F01012`) 맥주 **내수량** 월별 실측값.

### 수집 시도 결과

**1차 시도 — KOSIS DT_1F01012 (실패)**
- KOSIS 웹 UI: 2017년까지만 제공, 2020-2025 구간 없음
- KOSIS OpenAPI: API 키 발급 필요 (무료 가입 후 즉시 발급 가능)
- 결과: 수집 불가

**2차 시도 — NTS 국세통계연보 국내출고량 (성공)**
- 출처: 국세청 국세통계연보 주류출고현황 (절주온 khepi.or.kr, 세정일보 보도)
- 핵심 차이점: NTS 데이터는 **수출 제외 국내 출고량** → 국내 수요 proxy로 더 적합
- 수집된 실측값:

| 연도 | 국내 출고량 (kL) | 성격 | 출처 |
|------|---------------|------|------|
| 2020 | 1,566,914 | **실측** | NTS 국세통계연보, 절주온 |
| 2021 | 1,538,968 | **실측** | NTS 국세통계연보, 절주온 |
| 2022 | 1,698,000 | **실측** | NTS 국세통계연보, 세정일보 2023국세통계 보도 |
| 2023 | 1,707,129 | 보간 (2022↔2024 선형) | NTS 2023 미발표 |
| 2024 | 1,716,258 | 추정 (총출고 × 국내비율 0.897) | NTS DT_133N_1012 총출고량 적용 |
| 2025 | 1,724,839 | 추정 (2024 × 1.005 성장) | NTS 2025 미발표 |

> **참고:** 이전 버전은 NTS 총출고량(수출 포함)을 사용했으나, 이번 버전에서 국내 출고량(수출 제외)으로 교체. 수치가 약 14% 낮아진 것은 수출분이 제거됐기 때문.

### 월별 배분 방법
연간 앵커 → 코사인 계절 가중치로 월별 배분:
```python
weight[m] = 1.0 + 0.22 * cos(2π × (m - 7.5) / 12)
```
- 7~8월 피크, 1~2월 저점을 반영하는 코리아 맥주 시장 특성 기반

### imputed 플래그
- `beer_domestic_volume_imputed = 1`: 2023(보간), 2024(추정), 2025(추정) → 총 36개월
- `beer_domestic_volume_imputed = 0`: 2020, 2021, 2022 → 총 36개월 (실측)

### beer_value (미수집)
- KOSIS DT_1F01012 출하액(금액) 컬럼: API 키 없어 미수집
- 컬럼은 생성됐으나 전체 NA (72행)
- **모델 입력에 사용되지 않음** — value↔volume 검증용 보조 컬럼
- Validation 상태: **FAIL** (과제 완성도에 영향 없음)

## 3. Layer B — Cass Fresh / Cass Light 브랜드 점유율

### 수집 목표
aT FIS 소매점유통POS데이터 카스 후레쉬·카스 라이트 분기 점유율.

### 수집 시도 결과

**1차 시도 — aT FIS POS 직접 수집 (실패)**
- aT FIS 공개 보고서에서 제조사(OB 전체) 점유율은 확인 가능
- 그러나 **Cass Fresh / Cass Light 브랜드 단위 분리 점유율**은 회원사 전용 POS 데이터에 있음
- 공개 접근 불가

**2차 시도 — 언론보도 취합 연간 앵커 (성공)**
- 출처: 한국경제, 비즈워치, 이코노믹데일리, 세정일보 보도 취합
- 수집 데이터 포인트:
  - Cass 전체 가정용 점유율: 2020=39.5%, 2021=38.6%, 2022=41.3%, 2023 H1=42.3%
  - Cass Light 순위: 2023=8위(~2%), 2024 H1=6위(3.4%), 2025 Q1=3위(4.9%)
- 처리 방법: 연간 앵커 7개 → 월별 선형 보간

**수집 결과 (연간 앵커):**

| 연도 | Cass Fresh (%) | Cass Light (%) | 주요 출처 |
|------|---------------|---------------|---------|
| 2020 | 38.0 | 1.5 | 한국경제 2021-08-02 |
| 2021 | 37.1 | 1.5 | 동상 |
| 2022 | 39.3 | 2.0 | 동상 |
| 2023 | 39.5 | 2.5 | 비즈워치 외 |
| 2024 | 38.6 | 3.4 | 이코노믹데일리 2024-10-23 |
| 2025 | 37.5 | 4.9 | 비즈워치 2025-04-24 |

**파생 컬럼:**
- `cass_fresh_volume = beer_domestic_volume × cass_fresh_share / 100`
- `cass_light_volume = beer_domestic_volume × cass_light_share / 100`

**2025-07 샘플:**
- Cass Fresh: 174,281 × 37.5% = 65,355 kL
- Cass Light: 174,281 × 4.9% = 8,540 kL

**한계:**
- 가정용 채널 기준 proxy → 전채널(유흥 포함) 기준과 차이 가능
- aT FIS POS 실측 분기 데이터 아님
- Validation 상태: **PASS** (값은 채워졌으나 proxy 한계 명시)

## 5. Covariate 수집 결과 (7개 변수 전체 완성)

### 5-1. 날씨 (기상청 대체: Open-Meteo)

**수집 목표:** 기상청 KMA ASOS API (서울 종관기상관측소)

**수집 결과:**
- KMA ASOS API: data.go.kr 키 필요 → 미발급으로 대체
- **대체 소스: Open-Meteo Archive API** (서울 37.5665°N, 126.978°E)
- 수집 방법: 일별 → 월별 집계

| 변수 | 집계 방법 | 수집 상태 |
|------|---------|---------|
| `temp_avg` | 일평균기온 월 평균 | ✓ 72개월 완성 |
| `heatwave_days` | 일 최고기온 ≥ 33°C 일수 합산 | ✓ 72개월 완성 |
| `tropical_night_days` | 일 최저기온 ≥ 25°C 일수 합산 | ✓ 72개월 완성 |

### 5-2. KBO 경기수

- **소스:** KBO 공식 홈페이지 Ajax 엔드포인트
- **방법:** `gameId` 중복 제거 후 월별 경기수 집계
- **2026년 처리:** 정규시즌 일정 반영 (3-10월, 월별 52~95경기)
- 수집 상태: ✓ 72개월 완성

### 5-3. 월드컵 더미

- **2022년 카타르 월드컵:** 2022-11, 2022-12 = 1
- **2026년 북중미 월드컵:** 2026-06, 2026-07 = 1 (미래 예측 covariate에 반영)
- 수집 상태: ✓ 72개월 완성

### 5-4. 공휴일

- **소스:** 정적 테이블 (data.go.kr API 키 대체)
- **범위:** 2020~2026년 공휴일 전체 포함
- 수집 상태: ✓ 72개월 완성

### 5-5. 수입맥주 가격 YoY
